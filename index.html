02 / THE THEORY

From water balance
to feedback control.

No leap of faith. Follow the model from a single tank to the closed loop, one idea at a time.

THE RESULT

H₃(s)SP(s)

=

KcR(τs + 1)³ + KcR

H₃ and SP here are deviations from the initial steady state. The charts show absolute levels.

01 Start with the tank balance

A tank stores water whenever more enters than leaves. With constant cross-sectional area A, conservation of volume gives:

A dhᵢ/dt = qᵢ₋₁ − qᵢ

A is in m², h in m, and q in m³/min. Both sides therefore have units of m³/min. At steady state all flows equal q̄ and all levels equal h̄.

02 Gravity drainage and a local approximation

For free gravity discharge, write q = c√h, with c collecting outlet area, discharge coefficient, and gravity. More head means more outflow. Near h̄, a first-order Taylor approximation gives:

Δq ≈ [q̄/(2h̄)] Δh = Δh/R

Thus R = 2h̄/q̄, measured in min/m². It is the slope dh/dq at the operating point, not simply h̄/q̄. A large R means a small level change causes a relatively small outflow change.

03 Meet resistance R and time constant τ

Substitute Δq = Δh/R into the balance and define τ = AR. Then τ has units of minutes:

τ dΔh/dt + Δh = R Δqin

For a single tank with zero initial deviation, the Laplace transform is H/Qin = R/(τs + 1). Its flow-to-flow transfer function is Qout/Qin = 1/(τs + 1).

04 Put three tanks in series

The first two tanks pass an outlet flow to the next tank. Multiply two flow-to-flow blocks by the final flow-to-level block:

Gp(s) = [1/(τs + 1)]² × R/(τs + 1)
= R/(τs + 1)³

The numerator is R, not R³: each intermediate conversion from level to outlet flow contributes 1/R. The three identical time constants create three lags. These tanks are noninteracting: each outlet drains freely, so the next tank’s level does not change the upstream outflow.

05 Close the negative feedback loop

Let r be the setpoint deviation, y = Δh₃ the measured output, e = r − y the error, u = Kc e the controller’s flow change, and d an added inlet disturbance.

Y = Gp [Kc(SP − Y) + D]

Collect the Y terms. For a setpoint change alone, Y/SP = KcGp/(1 + KcGp). For a disturbance alone, Y/D = Gp/(1 + KcGp).

H₃/SP = KcR / [(τs + 1)³ + KcR]
H₃/D = R / [(τs + 1)³ + KcR]

Kc has units m²/min. Multiplying by R makes loop gain L = KcR dimensionless. A stable constant-input response reaches Δh₃,∞ = (Lr + Rd)/(1 + L). Setpoint-only offset is r/(1 + L); a disturbance changes the offset too.

06 Why the boundary is exactly KcR = 8

The characteristic polynomial is τ³s³ + 3τ²s² + 3τs + (1 + L). For a cubic with positive coefficients, the Routh stability condition is:

(3τ²)(3τ) > τ³(1 + L)
9 > 1 + L → L < 8

With nonnegative Kc, the stable region is 0 ≤ L < 8. At L = 8, the poles are −3/τ and ±j√3/τ: a decaying mode plus sustained oscillation. Above 8, a conjugate pair moves into the right half-plane and oscillations grow.

The critical controller gain is Kc,crit = 8/R, so it changes with the tank operating point. The marginal period is 2πτ/√3. A perfectly unforced zero-state run stays flat even when the model is unstable; stability describes what a disturbance would excite.

THE SHARED BASELINE

Worked example: Kyle’s default case

A = 1 m², h̄ = 1 m, q̄ = 0.20 m³/min, Kc = 0.20 m²/min, ΔSP = 0.20 m, d = 0, and duration = 120 min.

R = 10 min/m², τ = 10 min, and L = 2. The stable final level change is 0.1333 m, leaving 0.0667 m of offset.

READ THE RESULTS CORRECTLY

Overshoot is not setpoint crossing.

Overshoot measures how far the response travels past its own steady-state change, divided by the magnitude of that change. A response can overshoot its final value and still never reach the setpoint.

Settling uses a 2% band around the response’s steady change; its reported time is elapsed after the last applied input. A short run may not demonstrate settling. Marginal and unstable runs have no settling metrics.

Assumptions: identical constant-area tanks; incompressible liquid; fixed outlet geometry; small deviations; ideal sensor and actuator; no delay, saturation, or integral action. Negative levels or total flows, and large deviations from h̄, expose limits of the linear approximation.

// Deviation states: x = [Δh₁, Δh₂, Δh₃]
const R = 2 * level / flow;
const tau = area * R;
const u = gain * (setpoint - x[2]);

// One balance per tank
dx1 = (R * (u + disturbance) - x[0]) / tau;
dx2 = (x[0] - x[1]) / tau;
dx3 = (x[1] - x[2]) / tau;
